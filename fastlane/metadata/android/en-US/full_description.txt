Modern Android smartphones require a USB-C to 3.5mm adapter or DAC for wired listening. However, popular DACs (such as the Apple USB-C Headphone Adapter) initialize internal hardware volume registers to an attenuated default (-20 dB to -40 dB). Because Android does not adjust hardware volume registers, headphones remain quiet even with the system slider set to 100%.

DacVolumeFix resolves this automatically by sending standard USB Audio Class 2 commands to set the internal hardware volume register to full 0 dB dynamic range.

Features:
* Pure Kotlin implementation with zero native C++ binaries (2.4 MB)
* Windowless background execution on DAC plug-in
* Suppresses recurring Android audio capture warning popups
* Continuous -80 dB to 0 dB volume adjustment slider
* Zero idle battery impact (event-driven, no background polling)
* 100% offline with zero internet permissions and zero telemetry
